## Fixes

- **Usage no longer bounces back up while Claude Code is working.** When you sent a message, the ring could briefly jump back to an older, lower usage number and then drop again. Within a limit window, TokenTide now only lets the number go up; a new window still starts from scratch.
- **The right-click menu shows the current version**, just above **Check for Updates…**.

This is the first release delivered by the auto-updater. If you're on v0.1.4 and kept TokenTide in `/Applications`, it will install itself within 6 hours, or right away from right-click → **Check for Updates…**.
