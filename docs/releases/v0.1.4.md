## What's new

- **Automatic updates.** TokenTide now checks GitHub every 6 hours and installs new releases by itself. An update installs only if it's signed by the same Developer ID and notarized by Apple. You can turn this off from the right-click menu. This is the last version you need to download by hand. Keep the app in `/Applications`.
- **Bigger ring for big screens.** Right-click → **Size** lets you pick Small, Medium, Large or Extra Large. The ring is redrawn at the chosen size, so it stays crisp.
- **Fable weekly limit (Max and Ultra).** It shows quietly as **7d Fable** in the panel once you've used more than half of it, and it never takes over the ring. Other per-model weekly limits follow the same rule.
