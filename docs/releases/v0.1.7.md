## Fixes

- **Fable (and other per-model weekly limits) now show up without a manual Refresh.** These limits come only from Anthropic's usage endpoint. The Claude Code status line doesn't carry them, and it can't see usage from the desktop app. With the status line on, TokenTide used to check that endpoint just once an hour, and opening the panel didn't refresh it either. Now, once a per-model limit reaches 40%, TokenTide checks every 10 minutes, and opening the panel fetches again if the data is more than 15 minutes old.
